# Attentes pour la soutenance (hors cahier des charges)
Pour votre soutenance, voici les éléments attendus en complément du cahier des charges :

✅ Planification & Conception

- Un rétroplanning détaillant les étapes du projet.
- Des wireframes (2 à 3 pages) adaptés aux breakpoints définis.

✅ Qualité du Code & Front-End

- Utilisation des balises sémantiques (éviter l'excès de <div> inutiles).
- Importation d'une police personnalisée (en local ou via API).
- Un <head> bien complété (title dynamique, meta description, favicon, etc.).
- Utilisation d’un préprocesseur CSS (SASS/SCSS).
- Un développement Mobile-First (si Desktop-First, l'argumentation doit être solide).
- Manipulation du DOM via JavaScript (React bien structuré est accepté).

✅ Back-End & Base de Données

- Plusieurs requêtes HTTP (avec une API back-end).
- Un MCD contenant au moins 3 tables et une relation (si base SQL).
- Une architecture MVC (Modèle - Vue - Contrôleur).
- Une authentification sécurisée, incluant :
- Validation des données (longueur du mot de passe, etc.).
- Hash du mot de passe.
- Middleware de protection des routes avec jsonwebtoken.
- Stockage du token dans un cookie sécurisé.

✅ Back-Office & Sécurité

- Un back-office sécurisé avec au moins un CRUD complet.
- Sécurisation des routes front et back (via middleware et JWT).

✅ Versioning & Présentation

- Un repository Git propre avec un README.md détaillé (installation, configuration, utilisation).
- Projet fonctionnel et hébergé sur votre IDE 3WA.
- Code propre et maintenable :
   - Bonne indentation.
   - Pas de répétitions inutiles.
   - Conventions de nommage respectées (camelCase, PascalCase, etc.).

✅ Présentation & Améliorations

- Explication des améliorations fonctionnelles apportées.
- Discussion sur les problèmes rencontrés et les solutions mises en place.
